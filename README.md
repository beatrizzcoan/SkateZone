# SkateZone

Plataforma colaborativa para localização de pistas, informações sobre eventos de skate e conexão da comunidade skatista.

## Sobre o projeto

O SkateZone foi concebido para resolver a fragmentação de informações no universo do skate e promover maior conexão entre a comunidade. A aplicação funciona como um hub comunitário onde skatistas mapeiam pistas existentes, cadastram novas, avaliam a infraestrutura dos locais, acompanham a agenda de campeonatos e recebem lembretes dos eventos que possuem interesse.
